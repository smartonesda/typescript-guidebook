# ⚙️ Instalasi

Clone repository

```bash
git clone https://github.com/smartonesda/typescript-guidebook.git
```

Masuk ke project

```bash
cd typescript-guidebook
```

Install dependency

```bash
npm install
```

Jalankan development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview hasil build

```bash
npm run preview
```
