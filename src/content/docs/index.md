# Mengapa Belajar TypeScript?

JavaScript merupakan bahasa pemrograman yang digunakan oleh hampir semua website modern.

Namun, JavaScript memiliki kelemahan karena banyak kesalahan baru diketahui ketika program dijalankan.

TypeScript hadir untuk membantu programmer menemukan kesalahan lebih awal sehingga kode menjadi:

- Lebih aman
- Lebih mudah dipelajari
- Lebih mudah dikembangkan
- Lebih mudah dikerjakan secara tim

Saat ini TypeScript digunakan oleh banyak perusahaan teknologi di dunia dan menjadi standar dalam pengembangan aplikasi modern.

# Cara Menggunakan Guidebook Ini

Agar hasil belajarmu maksimal, ikuti beberapa langkah berikut.

1. Pelajari materi sesuai urutan bab.
2. Ketik ulang setiap contoh kode yang diberikan.
3. Jalankan seluruh contoh menggunakan **TSX**.
4. Jangan takut mencoba dan bereksperimen.
5. Kerjakan seluruh latihan dan challenge.
6. Selesaikan mini project di setiap bab.

> **Tips**
>
> Jangan takut ketika menemukan error.
>
> Error adalah bagian dari proses belajar seorang programmer.

# Target Akhir

Setelah menyelesaikan seluruh guidebook ini, kamu diharapkan mampu:

- Memahami dasar-dasar TypeScript.
