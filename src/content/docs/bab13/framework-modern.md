# Framework Modern Terpopuler

## Tujuan Pembelajaran
Setelah menyelesaikan halaman ini, kamu diharapkan dapat:
- Mengenali nama-nama framework frontend dan backend terpopuler di industri.
- Memahami kapan sebaiknya menggunakan masing-masing framework tersebut.
- Memiliki gambaran luas tentang alat kerja developer profesional.

---

## Pendahuluan
Di industri nyata, developer jarang menulis kode web dari nol (*vanilla javascript/typescript*). Mereka menggunakan **Framework** — kumpulan pustaka kode terstruktur yang mempercepat proses pembuatan aplikasi sesuai standar pola desain industri.

---

## Penjelasan: Ekosistem Framework TypeScript

Berikut adalah daftar framework utama yang wajib kamu ketahui di ekosistem TypeScript:

### 1. Sisi Frontend (Aplikasi Web Tampilan)
- **React**: Library buatan Meta. Memiliki ekosistem terbesar di dunia dan paling banyak lowongan kerjanya.
- **Vue.js**: Framework yang paling ramah pemula, memiliki dokumentasi bahasa Indonesia yang sangat baik, dan sangat disukai di sekolah/vocational.
- **Angular**: Framework buatan Google. Sangat terstruktur, menggunakan OOP ketat, dan banyak digunakan di bank atau perusahaan besar.
- **Svelte**: Pendatang baru yang berfokus pada performa super cepat tanpa overhead virtual DOM.

### 2. Sisi Backend (Server & API)
- **Express.js**: Standar industri untuk web server minimalis Node.js.
- **NestJS**: Framework backend modern yang mengimplementasikan OOP, Decorator, dan arsitektur modular yang rapi mirip seperti Angular.

### 3. Sisi Fullstack (Gabungan Frontend & Backend)
- **Next.js**: Framework berbasis React yang sangat populer untuk membuat website SEO-friendly berkecepatan tinggi.
- **Nuxt.js**: Framework berbasis Vue.js untuk kebutuhan fullstack yang serupa.

## Tips Dunia Industri
:::note[Kuasai Satu Dulu Sampai Ahli]
Jangan mencoba mempelajari semua framework di atas sekaligus. Ini adalah kesalahan pemula yang memicu rasa lelah (*burnout*). Pilihlah **satu** kombinasi (misal: Vue.js untuk frontend dan Express untuk backend) dan pelajari secara mendalam sampai kamu bisa membuat satu aplikasi lengkap secara mandiri.
:::
