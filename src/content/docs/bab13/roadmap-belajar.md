# Peta Jalan Belajar (Roadmap)

## Tujuan Pembelajaran
Setelah menyelesaikan halaman ini, kamu diharapkan dapat:
- Memilih jalur belajar (*roadmap*) teknologi berikutnya secara mantiri.
- Memvisualisasikan peta jalan untuk Frontend, Backend, dan Fullstack Developer.

---

## Pendahuluan
Agar proses belajarmu setelah lulus buku ini terarah, halaman ini menyajikan visualisasi **Roadmap Belajar** terpadu. Pilihlah satu jalur yang paling menarik minatmu dan ikuti langkahnya secara bertahap.

---

## 1. Peta Jalan Jalur Frontend Developer

Jalur ini berfokus pada visual, antarmuka web, dan pengalaman pengguna:

```text
[ DASAR WEB ] ──► HTML & CSS (Desain Halaman Statis)
      │
      ▼
[ PROGRAMMING ] ──► JavaScript & TypeScript (Panduan Buku ini)
      │
      ▼
[ STYLING ] ──► Tailwind CSS (Kerangka Desain Cepat)
      │
      ▼
[ FRAMEWORK SPA ] ──► Vue.js atau React (Aplikasi Web Interaktif Modern)
      │
      ▼
[ STATE & DEPLOY ] ──► State Management (Zustand/Pinia) & Deploy ke Vercel 🚀
```

---

## 2. Peta Jalan Jalur Backend Developer

Jalur ini berfokus pada database, server, keamanan, dan logika data di balik layar:

```text
[ RUNTIME ] ──► Node.js (Menjalankan JS/TS di komputer/server)
      │
      ▼
[ HTTP SERVER ] ──► Express.js (Membuat web server dasar & routing)
      │
      ▼
[ DATABASE SQL ] ──► PostgreSQL / MySQL & Bahasa Query SQL
      │
      ▼
[ DATABASE ORM ] ──► Prisma ORM (Menghubungkan TypeScript ke SQL secara aman)
      │
      ▼
[ FRAMEWORK ADV ] ──► NestJS (Pembuatan Server Skala Enterprise menggunakan OOP) 🚀
```

---

## 3. Peta Jalan Jalur Fullstack Developer (Next.js)

Jalur ini menggabungkan kedua dunia di atas menggunakan satu bahasa (TypeScript):

```text
[ TYPESCRIPT ] ──► Selesaikan Buku ini (Kunci Utama)
      │
      ▼
[ REACT FRAMEWORK ] ──► Pelajari React Dasar (Komponen & State)
      │
      ▼
[ FULLSTACK ENGINE ] ──► Next.js (Server & Client terpadu dalam satu project)
      │
      ▼
[ DATABASE INTEGRATION ] ──► Hubungkan Next.js ke PostgreSQL menggunakan Prisma ORM
      │
      ▼
[ CLOUD DEPLOYMENT ] ──► Deploy aplikasi Next.js secara instan ke Vercel Cloud 🚀
```

---

## Tips Dunia Industri
:::note[Belajarlah Secara T-Shaped]
Jadilah developer dengan model **T-Shaped**:
- Miliki pemahaman **luas** tentang seluruh alur teknologi (horisontal / bagian atas huruf T).
- Miliki keahlian **sangat mendalam** pada salah satu bidang saja (vertikal / kaki huruf T), misalnya sangat jago di sisi Vue.js Frontend.
:::
