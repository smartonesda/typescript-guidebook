# Fullstack Developer Roadmap

## Tujuan Pembelajaran
After this page, you should be able to explain the role of a Fullstack Developer, identify the advantages of using a single language (TypeScript) for both client and server, and understand the role of Next.js.

---

## Pendahuluan
Mengapa mempelajari TypeScript sangat menguntungkan? Karena TypeScript adalah satu dari sedikit bahasa pemrograman yang bisa digunakan di **sisi frontend** (browser) sekaligus **sisi backend** (server). 

Jika kamu menguasai keduanya, kamu bisa menjadi seorang **Fullstack Developer** yang mampu membangun seluruh sistem aplikasi sendirian dari nol.

---

## Penjelasan: Apa itu Fullstack Developer?

Seorang **Fullstack Developer** adalah software engineer yang memiliki kemampuan untuk membangun antarmuka frontend sekaligus memprogram mesin server backend.

### Keuntungan TypeScript untuk Fullstack:
Di masa lalu, developer harus belajar PHP untuk backend dan JavaScript untuk frontend. Sekarang, dengan TypeScript, kamu cukup menguasai **satu bahasa** untuk mengendalikan seluruh sistem. Ini membuat proses coding jauh lebih cepat karena kamu bisa berbagi jenis tipe data (interface/class) yang sama antara kode server dan kode browser.

### Next.js: Framework Fullstack Terpopuler
Dalam ekosistem TypeScript, **Next.js** adalah framework fullstack yang sangat populer. Next.js menggabungkan React (frontend) dengan kemampuan server-side rendering dan API routes (backend) di dalam satu folder project terpadu.

### Roadmap Teknologi Lanjutan:
```text
HTML/CSS/TS ──► Framework Frontend (React/Vue) ──► Node.js Backend ──► Fullstack Framework (Next.js)
```

## Tips Dunia Industri
:::note[Kuasai Dasar Sebelum Menggunakan Framework Fullstack]
Next.js sangat hebat dan mempermudah pekerjaan. Namun, pastikan kamu sudah paham dasar-dasar cara kerja komunikasi HTTP request (Fetch API) dan cara kerja database secara terpisah terlebih dahulu. Memahami dasarnya akan mempermudahmu melakukan debug ketika project fullstack-mu mengalami error.
:::

## Ringkasan
- Fullstack Developer menguasai pembuatan frontend sekaligus backend aplikasi.
- TypeScript mempermudah fullstack development karena menggunakan satu bahasa di semua sisi.
- **Next.js** adalah framework fullstack terpopuler dalam ekosistem React/TypeScript.
