# Challenge BAB 13: Persiapan Karir

## Tujuan Pembelajaran
Setelah menyelesaikan challenge ini, kamu diharapkan dapat:
- Menyusun portofolio online nyata di GitHub.
- Merapikan CV dan profil LinkedIn sesuai standar industri.
- Bergabung dengan komunitas developer untuk memperluas relasi kerja.

---

## Pendahuluan
Ini adalah daftar tantangan terakhir di dalam buku ini. Tugasmu bukan lagi menulis kode pemrograman, melainkan **mempersiapkan dirimu sendiri** agar siap bersaing secara profesional di dunia industri software.

---

## Daftar 10 Tantangan Persiapan Karir

:::caution[Tantangan Nyata]
Kerjakan 10 tantangan ini secara bertahap selama semester akhir sekolahmu. Mintalah guru bimbingan konseling atau gurumu di sekolah untuk memeriksa hasil pekerjaanmu jika sudah selesai.
:::

### 1. Rapikan Profil GitHub
Gunakan foto asli profesional, isi bagian bio singkat, cantumkan email, dan buatlah repositori profil README khusus untuk mempercantik halaman depan akun GitHub-mu.

### 2. Publikasikan Final Project SIAKAD
Upload source code aplikasi SIAKAD BAB 11 milikmu ke dalam repositori GitHub baru. Pastikan nama repositori rapi (misal: `siakad-console-typescript`).

### 3. Tulis Dokumen README yang Stellar
Tulis file `README.md` pada repositori SIAKAD-mu secara lengkap: jelaskan fitur aplikasi, cara install, cara menjalankan dengan `tsx`, serta cantumkan namamu sebagai pembuatnya.

### 4. Deploy Project ke Render / Railway (Opsional)
Jika kamu sudah membuat versi web API sederhana, deploy aplikasi backend-mu ke cloud Render atau Railway agar link live demo bisa diakses publik.

### 5. Tulis Artikel Teknis Pertama
Buatlah akun di Medium, Dev.to, atau blog pribadimu. Tulis satu artikel singkat dalam bahasa Indonesia yang menjelaskan konsep yang paling kamu sukai di buku ini (misalnya: *"Mengenal Perbedaan var, let, dan const di TypeScript"*).

### 6. Buat Akun LinkedIn Profesional
Isi profil LinkedIn-mu lengkap dengan riwayat sekolah, keahlian teknismu, serta tautkan link akun GitHub dan artikel teknismu.

### 7. Susun CV ATS-Friendly (1 Halaman)
Buatlah CV bersih tanpa banyak hiasan grafis warna-warni yang membingungkan mesin pemindai HRD. Cantumkan nama, kontak, keahlian, dan link portofolio GitHub.

### 8. Bergabung dengan Komunitas Developer
Bergabunglah dengan minimal satu komunitas IT (misalnya: Discord Programmer Zaman Now, grup Telegram Kopi Coding, atau grup WhatsApp komunitas lokal). Mulailah menyapa dan berdiskusi secara sopan.

### 9. Latihan Wawancara Teknis Dasar
Mintalah teman sebangkumu untuk bermain peran (*roleplay*): temanmu bertindak sebagai interviewer yang menanyakan 5 pertanyaan dasar OOP/TypeScript, dan kamu menjawabnya secara lisan secara percaya diri.

### 10. Berkontribusi ke Typo Dokumentasi
Temukan satu salah ketik (typo) atau penjelasan kurang pas di repositori dokumentasi open source lokal/sekolah, lalu ajukan perbaikan (Pull Request) pertamamu.
