# Kontribusi Open Source

## Tujuan Pembelajaran
Setelah menyelesaikan halaman ini, kamu diharapkan dapat:
- Menjelaskan arti dari *Open Source*.
- Menyebutkan keuntungan berkontribusi ke project open source bagi siswa SMK.
- Mencari isu pemula (*good first issue*) di GitHub untuk mulai berkontribusi.

---

## Pendahuluan
TypeScript adalah bahasa pemrograman open source. Starlight, framework yang merender buku ini, juga open source. Artinya, seluruh kode sumbernya terbuka untuk umum di GitHub dan siapa saja — termasuk kamu yang masih berstatus siswa SMK — boleh ikut serta memperbaiki bug, menambah fitur, atau merapikan dokumentasinya.

---

## Penjelasan: Mengapa Harus Ikut Open Source?

Berkontribusi ke project open source adalah salah satu cara tercepat untuk menaikkan level keahlian coding-mu secara nyata:

1. **Belajar Membaca Kode Orang Lain**: Menulis kode sendiri itu mudah. Membaca dan memahami ribuan baris kode yang ditulis oleh programmer profesional di seluruh dunia adalah tantangan yang akan membuatmu jauh lebih cerdas.
2. **Belajar Code Review**: Kodenya tidak langsung diterima. Developer lain akan memeriksa kodemu, memberikan saran perbaikan, dan mengajarkanmu kebiasaan menulis kode yang benar.
3. **Membangun CV/Portofolio yang Kuat**: Jika kamu bisa menunjukkan bahwa kamu pernah berkontribusi di project open source populer, perusahaan akan sangat tertarik merekrutmu karena kamu terbukti bisa bekerja sama dalam tim global.

---

## Cara Mulai Berkontribusi bagi Pemula

Jangan langsung mencoba memperbaiki bug rumit di project besar. Mulailah secara bertahap:

- **Perbaiki Dokumentasi (Typo)**: Jika kamu membaca dokumentasi library lalu menemukan salah ketik atau penjelasan yang membingungkan, buatlah perbaikan (Pull Request) untuk merapikannya.
- **Cari Label "good first issue"**: Banyak project di GitHub menandai tugas-tugas mudah yang dikhususkan untuk pemula dengan label `good first issue` atau `beginner-friendly`.

## Tips Dunia Industri
:::note[Sopan dan Patuhi Aturan Kontribusi]
Setiap project open source memiliki berkas `CONTRIBUTING.md` yang berisi aturan cara menulis kode di project mereka. Bacalah berkas tersebut dengan teliti, bersikaplah sopan saat berdiskusi di kolom komentar isu, dan hargai masukan dari para pemilik project.
:::

## Ringkasan
- Open Source adalah project yang kode sumbernya terbuka untuk dimodifikasi siapa saja.
- Berkontribusi meningkatkan kemampuan membaca kode, kolaborasi Git, dan nilai jual CV.
- Mulailah dari perbaikan dokumentasi kecil atau mencari label `good first issue` di GitHub.
