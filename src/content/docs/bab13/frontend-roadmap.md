# Frontend Developer Roadmap

## Tujuan Pembelajaran
Setelah menyelesaikan halaman ini, kamu diharapkan dapat:
- Menjelaskan peran dan tanggung jawab dari seorang Frontend Developer.
- Menyebutkan teknologi lanjutan yang harus dipelajari di jalur Frontend.
- Mengetahui jenis portofolio yang diminati industri untuk posisi Frontend.

---

## Pendahuluan
Jika kamu menyukai aspek visual, kerapian tata letak web, animasi, dan ingin membuat antarmuka yang nyaman digunakan oleh pengguna, maka jalur **Frontend Developer** adalah pilihan yang sangat cocok untukmu.

---

## Penjelasan: Apa itu Frontend Developer?

Seorang **Frontend Developer** adalah software engineer yang bertanggung jawab membangun bagian aplikasi yang berinteraksi langsung dengan pengguna (tampilan visual website atau aplikasi).

### Tanggung Jawab Harian:
1. Menerjemahkan desain visual (dari Figma/Adobe XD) menjadi kode HTML, CSS, dan TypeScript yang interaktif.
2. Memastikan website tampil rapi saat dibuka di layar HP (responsive web design).
3. Melakukan pengambilan data (Fetch API) dari backend untuk ditampilkan di layar.
4. Mengoptimalkan kecepatan muat halaman web.

### Roadmap Teknologi Lanjutan:
```text
Dasar Web (HTML & CSS) ──► JavaScript/TypeScript ──► Framework SPA (Vue.js / React) ──► State Management
```

- **CSS Framework**: Tailwind CSS atau Bootstrap (untuk mempercepat pembuatan desain tampilan).
- **Modern SPA Framework**: **Vue.js** (ramah pemula) atau **React** (sangat populer di startup besar).
- **State Management**: Pinia (Vue) atau Redux/Zustand (React) untuk mengelola data global tampilan.

## Tips Dunia Industri
:::note[Fokus pada Kemudahan Pengguna (UX)]
Bagi seorang Frontend Developer, tampilan yang indah saja tidak cukup. Tampilan harus mudah dipahami oleh pengguna awam. Pastikan ukuran tombol cukup besar di layar HP, warna teks mudah dibaca (kontras tinggi), dan berikan indikator loading yang jelas saat aplikasi sedang mengambil data dari internet.
:::

## Ringkasan
- Frontend Developer bertugas membuat tampilan visual dan logika interaksi pengguna.
- Teknologi wajib: HTML, CSS, TypeScript, dan salah satu framework (Vue.js/React).
- Portofolio ideal: Website e-commerce tiruan, dashboard kelola nilai, atau aplikasi cuaca interaktif.
