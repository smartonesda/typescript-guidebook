## Penjelasan Singkat Setiap Software

### Node.js

Node.js adalah program yang memungkinkan komputer kamu menjalankan kode JavaScript dan TypeScript. Tanpa Node.js, kamu tidak bisa menjalankan program TypeScript di komputermu.

Node.js juga menyertakan **npm** — program untuk menginstall paket/library.

### VS Code

VS Code (Visual Studio Code) adalah editor kode buatan Microsoft. Ini adalah tempat kamu akan menulis semua kode TypeScript kamu. VS Code memiliki dukungan sangat baik untuk TypeScript karena keduanya dibuat oleh Microsoft.

### TypeScript (tsc)

Ini adalah compiler resmi TypeScript. Kita perlu menginstallnya untuk mendapatkan kemampuan pemeriksaan tipe. Meskipun dalam proses belajar kita akan menggunakan TSX untuk menjalankan kode, TypeScript tetap dibutuhkan sebagai fondasi.

### TSX

TSX adalah alat yang memungkinkan kita menjalankan file TypeScript langsung tanpa perlu langkah kompilasi terpisah. Ini akan sangat mempercepat proses belajar kita.

## Persyaratan Sistem

:::note[Spesifikasi Minimum]

- **Sistem Operasi:** Windows 10/11, macOS 10.15+, atau Linux (Ubuntu 18.04+)
- **RAM:** Minimal 4 GB (disarankan 8 GB)
- **Storage:** Minimal 5 GB kosong
- **Koneksi Internet:** Dibutuhkan untuk mengunduh software
  :::

:::tip[Tips untuk Siswa]
Jika laptopmu memiliki spesifikasi rendah, jangan khawatir. Node.js, VS Code, dan TSX adalah software yang ringan. Laptopmu kemungkinan besar masih bisa menjalankannya dengan baik.
:::

## Checklist Instalasi

Gunakan checklist ini untuk melacak progres instalasimu:

- [ ] Node.js terinstall dan bisa dijalankan
- [ ] VS Code terinstall
- [ ] TypeScript terinstall secara global
- [ ] TSX terinstall secara global
- [ ] Project pertama berhasil dibuat
- [ ] Program pertama berhasil dijalankan

---

## Urutan Instalasi

:::caution[Penting: Ikuti Urutan Ini]
Install software sesuai urutan di atas. Node.js harus diinstall terlebih dahulu karena TypeScript dan TSX diinstall menggunakan npm (yang merupakan bagian dari Node.js).
:::

Urutan yang benar:

1. Node.js (termasuk npm) → dulu
2. VS Code → bisa kapan saja
3. TypeScript → setelah Node.js
4. TSX → setelah Node.js

- Semua software gratis dan tersedia untuk Windows, macOS, dan Linux
