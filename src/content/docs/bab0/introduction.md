Selamat datang di **BAB 0** — babak pertama perjalanan belajar TypeScript kamu.

Sebelum kita mulai menulis kode, ada beberapa hal penting yang perlu kita pahami bersama. Di BAB 0 ini, kita **tidak** akan langsung menulis TypeScript yang rumit. Kita akan membangun fondasi terlebih dahulu — seperti seorang pembangun rumah yang selalu memulai dari pondasi, bukan dari atap.

---

## Tujuan Pembelajaran

Setelah menyelesaikan BAB 0 secara keseluruhan, kamu akan mampu:

- Menjelaskan apa itu programming dengan bahasa kamu sendiri
- Memahami hubungan antara HTML, CSS, JavaScript, dan TypeScript
- Menjelaskan perbedaan JavaScript dan TypeScript
- Menyiapkan laptop untuk belajar TypeScript
- Menulis dan menjalankan program TypeScript pertama kamu

---

## Apa Saja yang Ada di BAB 0?

BAB 0 dibagi menjadi beberapa halaman. Setiap halaman membahas **satu topik saja** supaya kamu bisa fokus dan tidak bingung.

| Bagian         | Topik yang Dipelajari                                  |
| -------------- | ------------------------------------------------------ |
| **Pengenalan** | Apa itu programming, computational thinking, dunia web |
| **Teknologi**  | HTML, CSS, JavaScript, TypeScript, dan perbedaannya    |
| **Persiapan**  | Instalasi Node.js, VS Code, TypeScript, dan TSX        |
| **Praktek**    | Membuat project pertama dan menulis program pertama    |
| **Penutup**    | Error corner dan ringkasan BAB 0                       |

---

## Format Setiap Halaman

Setiap halaman di guidebook ini menggunakan format yang konsisten supaya mudah diikuti:

1. **Tujuan Pembelajaran** — kamu akan tahu apa yang akan dipelajari sebelum mulai membaca
2. **Pengantar** — konteks singkat tentang topik
3. **Penjelasan** — konsep dijelaskan dengan bahasa yang sederhana
4. **Analogi Kehidupan Sehari-hari** — perbandingan dengan hal yang sudah kamu kenal
5. **Contoh** — kode atau ilustrasi konkret
6. **Catatan Penting** — hal-hal yang perlu diperhatikan
7. **Ringkasan** — poin-poin utama di akhir halaman

:::note[Catatan]
Tidak semua halaman memiliki semua bagian di atas. Halaman instalasi, misalnya, tidak selalu memiliki bagian analogi. Tapi setiap halaman selalu punya penjelasan yang jelas.
:::
